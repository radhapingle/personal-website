# Radha Pingle — Personal Website

Botanical portfolio with a short 3D scroll intro, then a readable site for recruiters.

**Live:** https://radhapingle.github.io/personal-website/

## Files

| File | What it holds |
| --- | --- |
| `index.html` | Intro + all page content |
| `styles.css` | Colors, fonts, layout |
| `intro.js` | Three.js botanical entrance |
| `site.js` | Nav, ambient petals, interactions |
| `assets/` | Profile photo + resume PDF |
| `classic/` | Previous dossier layout (backup) |

## Preview locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/

## Edit

- Text / links: `index.html`
- Look & feel: `styles.css`
- Resume: replace `assets/RadhaP_Resume.pdf`
- Photo: replace `assets/profile.jpg`
